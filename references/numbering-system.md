# 文件编号体系

> 文件编号体系说明

---

## 一、编号基本规则

### 1.1 标准格式

```
[公司代号]-[体系代号]-[层级代号]-[顺序号]-[版本号]
      ↓        ↓         ↓        ↓        ↓
   ABC      QMS        QP       001       A

示例完整解读：
ABC-QMS-QP-001-A
公司代号=ABC（公司英文缩写或拼音首字母）
体系代号=QMS（质量管理体系）
层级代号=QP（程序文件）
顺序号=001（三位数字流水号）
版本号=A（第A版）
```

### 1.2 编号组成说明

| 组成要素 | 位置 | 长度 | 说明 |
|---------|-----|------|------|
| 公司代号 | 第1段 | 2-4位 | 英文缩写或拼音首字母，全公司统一 |
| 体系代号 | 第2段 | 2-6位 | 区分不同管理体系 |
| 层级代号 | 第3段 | 2位 | 区分文件层级 |
| 顺序号 | 第4段 | 3位 | 001-999，同层级内流水 |
| 版本号 | 第5段 | 1-2位 | 字母或数字 |

## 三、体系代号详解

### 3.1 常见体系代号

| 代号 | 体系名称 | 适用标准 |
|-----|---------|---------|
| QMS | Quality Management System | ISO9001 |
| IATF | IATF16949汽车质量管理体系 | IATF16949 |
| EMS | Environmental Management System | ISO14001 |
| OHS | Occupational Health Safety | ISO45001 |
| QM | Quality Management | 医疗器械 |
| FSMS | Food Safety Management | ISO22000 |
| ISMS | Information Security | ISO27001 |

### 3.2 多体系文件编号

**方式一：共用基础文件**
```
ABC-QMS-QP-001-A  （QMS和IATF共用程序）
ABC-IATF-QP-001-A  （IATF专用程序）
```

**方式二：独立编号体系**
```
ABC-QMS-***-***-*   （QMS体系文件）
ABC-IATF-***-***-*  （IATF体系文件）
ABC-EMS-***-***-*   （EMS体系文件）
```

**推荐方式一**，减少重复文件，便于统一管理。

## 五、版本号规则

### 5.1 版本号格式

```
字母版本：A → B → C → ...（26个大写字母）
数字版本：1 → 2 → 3 → ...（正向流水）
草稿版本：0.1 → 0.2 → 0.3 → ...（内部使用，不外发）
```

### 5.2 版本升级规则

| 变更类型 | 版本升级 | 示例 |
|---------|---------|------|
| 重大修订（内容变化>30%） | 字母递增 | A → B |
| 一般修订（局部修改） | 数字递增 | 1 → 2 |
| 轻微修订（文字修正） | 数字递增 | 1 → 2 |
| 草稿阶段 | 0.1/0.2/... | 0.1 → 0.2 |

### 5.3 版本控制要求

**版本发布前：**
- 所有历史版本必须归档
- 保留变更记录
- 记录变更内容摘要

**版本发布后：**
- 旧版本立即回收
- 不得继续使用旧版本
- 新版本加盖"受控文件"章

**版本标识：**
- 文件封面：版本号明确标注
- 页眉/页脚：显示文件编号+版本号
- 电子文件名：包含版本号

| 供应商文件 | SUPP-[供应商代码]-[类型代号]-[序号] | SUPP-ABC-SPEC-01 |

### 6.2 外来文件受控编号

```
[公司代号]-EXT-[原文件编号]-[年份]-[受控版本]
示例：
ABC-EXT-GB19001-2016-A
公司代号=ABC
外来文件标识=EXT
原文件编号=GB19001
年份=2016
受控版本=A

客户文件示例：
ABC-EXT-CUST-TOYOTA-SPC-001-B
```

## 七、受控印章管理

### 7.1 印章类型

| 印章类型 | 颜色 | 使用场景 |
|---------|------|---------|
| 受控文件章 | 红色 | 加盖在受控文件首页右上角 |
| 作废文件章 | 红色 | 加盖在作废文件上，禁止使用 |
| 借阅文件章 | 蓝色 | 借阅的非受控文件 |
| 复印有效章 | 红色 | 受控文件复印后加盖 |

### 7.2 印章使用规范

**受控文件章位置：**
```
    ┌─────────────────────────┐
    │   ★受控文件★            │
    │  文件编号：ABC-QMS-QP-001│
    │  版本：A                │
    │  发放日期：2024-01-01   │
    │  份数：第 3 份 共 10 份  │
    └─────────────────────────┘
```

**印章使用要求：**
- 指定专人保管
- 使用前检查印章清晰度
- 盖在规定位置
- 登记使用台账

### 7.3 印章台账

| 印章编号 | 印章类型 | 启用日期 | 使用文件范围 | 保管人 | 状态 |

### 8.2 编号使用检查要点

| 检查项目 | 检查内容 | 判定标准 |
|---------|---------|---------|
| 唯一性 | 编号是否唯一 | 一个编号对应一个文件 |
| 规律性 | 编号是否按规则编排 | 符合层级、流水号规则 |
| 完整性 | 编号各部分是否完整 | 5个部分齐全 |
| 可读性 | 编号是否易读易记 | 能看出文件类型和层级 |
| 可扩展性 | 编号是否留有扩展空间 | 流水号至少3位 |

## 九、常见问题

**Q：新成立公司，编号从001开始吗？**
A：是的，从001开始。建议第一批文件集中编号，便于管理。

**Q：文件作废了，编号能重复使用吗？**
A：不能。作废的编号永久保留，新文件使用新的流水号。

**Q：外审后发现文件编号混乱，能重新编号吗？**
A：能，但属于重大变更。需要走变更流程，通知所有相关部门，同步更新所有引用。

**Q：子公司和母公司文件编号要区分吗？**
A：必须区分。用不同的公司代号，如ABC-HQ（母公司）、ABC-SZ（深圳子公司）。

**Q：外来文件用原编号还是重新编号？**
A：建议重新编号，便于统一管理和追溯。原件编号记录在备注栏。

**Q：作业指导书编号后面带P、E、Q是什么意思？**
A：这是分类标识，P=工序Process，E=设备Equipment，Q=品质Quality。便于识别文件类型。
