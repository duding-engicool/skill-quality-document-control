# 记录保存期限规范

> 记录保存期限规范

## 一、保存期限基本原则

### 1.1 法规优先原则

记录保存期限首先满足法规最低要求。法规有明确规定的，按法规执行；法规无规定的，按行业惯例和企业需要执行。

### 1.2 风险导向原则

- 高风险产品记录：保存至产品停止生产后10年或法规要求年限
- 一般产品记录：保存3年
- 临时/过渡性记录：保存1年或产品交付后1年

### 1.3 可追溯原则

记录保存期限必须满足产品质量可追溯的要求。追溯需要的记录，一个都不能少。

## 四、记录归档管理

### 4.1 归档时机

| 记录类型 | 归档时间 | 说明 |
|---------|---------|------|
| 日常记录 | 月度/季度末 | 定期汇总归档 |
| 阶段性记录 | 阶段结束 | 如项目结束、培训结束 |
| 长期保存记录 | 产生后1个月内 | 及时归档 |
| 临时记录 | 年末或项目结束 | 判定后归档或销毁 |

### 4.2 归档要求

**纸质记录归档：**
- 分类整理，按时间/类型排列
- 装订成册，封面标注内容/时间/保存期限
- 存放在干燥、防虫、防火的档案柜
- 设定保存期限提醒

**电子记录归档：**
- 存储在服务器指定目录
- 设置访问权限
- 定期备份（建议本地+云端双重备份）
- 命名规范，便于检索

## 六、电子记录管理要求

### 6.1 电子记录有效性要求

| 要求项 | 具体要求 |
|-------|---------|
| 可读性 | 格式通用，不依赖特定软件 |
| 完整性 | 不得部分保存或选择性保存 |
| 保密性 | 设置访问权限，未经授权不得修改 |
| 可追溯 | 记录修改历史（谁、什么时间、改了什么） |
| 备份 | 定期备份，建议每日增量+每周全量 |
| 归档 | 按保存期限要求及时归档 |

### 6.2 电子签名要求

如采用电子签名，需满足：
- 签名人身份可确认
- 签名与记录内容关联不可篡改
- 签名时间可追溯
- 符合法规认可的电子签名形式（CA证书等）

### 6.3 电子记录销毁

电子记录销毁需：
- 确认保存期限已满
- 获得销毁审批
- 删除文件并清空回收站
- 记录销毁日志
- 如已备份，需同步删除备份

## 七、记录销毁管理

### 7.1 销毁判定条件

满足以下条件，可申请销毁：
- 保存期限已满
- 记录状态为"待销毁"
- 无未解决的追溯需求
- 无法律纠纷或调查涉及

### 7.2 销毁审批流程

```
到期提醒 → 部门申请 → 质量部审核 → 档案室确认 → 主管领导批准 
→ 实施销毁 → 登记销毁记录 → 更新台账
```

## 九、常见问题

**Q：记录到期了可以自行销毁吗？**
A：不行。必须走审批流程，获得批准后才能销毁。

**Q：保存期限到了，但涉及法律纠纷怎么办？**
A：立即停止销毁申请，延长保存期限，直到纠纷解决。

**Q：电子记录和纸质记录保存期限一样吗？**
A：原则上一样。但电子记录需要额外满足电子文件管理要求。

**Q：顾客要求保存期限超过法规要求，以哪个为准？**
A：以顾客要求为准。合同约定的，按合同执行。

**Q：记录销毁后才发现需要追溯怎么办？**
A：这是一个严重问题。需要分析原因，防止再次发生。同时尽可能通过其他途径恢复（如备份、复印件等）。

**Q：每年有多少记录需要销毁？**
A：建议每季度清理一次即将到期的记录，编制销毁计划。
